# FastFind

FastFind is a lightweight, high-performance desktop file search utility built with Python.

---

## Requirements

- Python 3.8+
- PyQt6

## Installation

1. Clone the repository:
```bash
   git clone https://github.com/Miaoumap24/FastFind.git
   cd FastFind

```

2. Install dependencies:
```bash
pip install -r requirements.txt

```



## Usage

Run the application with:

```bash
python main.py

```

* Wait a few seconds upon launching for the initial filesystem indexing to complete.
* Type any query in the search bar to filter results instantly.
